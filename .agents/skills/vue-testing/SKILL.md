# Pruebas adaptadas para Primary Academy

- Usar Vitest para lógica crítica y pruebas unitarias.
- Probar contratos públicos y comportamiento observable, no implementación interna.
- Aislar tiempo y aleatoriedad mediante fuentes inyectables.
- Usar pruebas Playwright solo si aportan al flujo real y están disponibles.
- Evitar snapshots como única evidencia.
- Priorizar casos que fallen si cambia la aleatorización, la corrección, la puntuación o el ciclo de partida.
