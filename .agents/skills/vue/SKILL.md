# Vue adaptada para Primary Academy

- Usar Vue 3, Composition API, `<script setup lang="ts">` y `script setup`.
- Mantener estado mínimo y explícito; derivar datos con `computed`.
- Usar props hacia abajo y eventos hacia arriba.
- Mantener responsabilidades separadas: rutas/presentación, contenido, evaluación y sesión.
- Extraer una composición solo cuando encapsule una responsabilidad útil; no crear capas vacías.
- Evitar features Vue opcionales sin necesidad demostrada.
- Mantener templates declarativos y contratos de componentes tipados.
- Validar funcionalidad antes de optimizar rendimiento.
