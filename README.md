# Primary Academy

Aplicación educativa ligera para practicar verbos irregulares en español e inglés.

## Requisitos

- Node.js 22 LTS o compatible.
- npm 10 o compatible.

## Instalación

```bash
npm ci
npm run dev
```

Abre la URL que muestre Vite.

## Comprobaciones

```bash
npm run lint
npm run typecheck
npm run test
npm run build
npm run check:bundle
npm run check
```

El presupuesto exige como máximo 150 KB JS gzip, 35 KB CSS gzip y 350 KB de transferencia sin comprimir.

## Flujo

Inicio → Inglés → Verbos irregulares → Quiz clásico → Partida → Resultados → Revisión de errores.
